# SITEWATCH
## Service Consistency Checker

An automated service monitoring, incident tracking, and email alerting application built with Node.js, Express, MySQL, MongoDB, and Nodemailer.

---

## System Requirements

Before setting up the project, ensure you have the following installed on your system:

* **Node.js**: v18.0.0 or higher
* **npm**: v9.0.0 or higher
* **MySQL Server**: v8.0 or higher
* **MongoDB Server**: v6.0 or higher (or a cloud MongoDB Atlas connection)
* **Google Account**: Required for sending email alerts via Gmail SMTP (with 2-Step Verification enabled)

---

## Installation & Setup Guide

### 1. Clone the Repository

Clone the project repository to your local machine and navigate into the project directory:

```bash
git clone <repository-url>
cd dev-tools

```

---

### 2. Install Dependencies

Install all required Node.js package dependencies:

```bash
npm install

```

---

### 3. Configure Environment Variables

Create a `.env` file in the root directory of the project:

```bash
touch .env

```

Add the following environment variables to your `.env` file, replacing the placeholder values with your actual configuration:

```env
# Server Configuration
PORT=3000

# MySQL Database Configuration
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_mysql_password
MYSQL_DATABASE=service_checker

# MongoDB Configuration
MONGO_URI=mongodb://localhost:27017/service_checker

# Email Alert Configuration (Gmail SMTP)
GMAIL_USER=your-email@gmail.com
GMAIL_APP_PASS=xxxx xxxx xxxx xxxx
ALERT_EMAIL_TO=recipient1@gmail.com, recipient2@example.com

```

---

### 4. Database Setup

#### A. MySQL Database Initialization

Log into your MySQL instance and run the following commands to create the database schema:

```sql
CREATE DATABASE IF NOT EXISTS service_checker;
USE service_checker;

-- Monitors Table
CREATE TABLE IF NOT EXISTS monitors (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    url VARCHAR(2048) NOT NULL,
    expected_status INT DEFAULT 200,
    timeout_ms INT DEFAULT 10000,
    is_active BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    deleted_at DATETIME NULL
);

-- Check Runs Table
CREATE TABLE IF NOT EXISTS check_runs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    started_at DATETIME NOT NULL,
    finished_at DATETIME NULL,
    trigger_type VARCHAR(50) DEFAULT 'manual',
    total_count INT DEFAULT 0,
    up_count INT DEFAULT 0,
    down_count INT DEFAULT 0,
    duration_ms INT DEFAULT 0
);

-- Incidents Table
CREATE TABLE IF NOT EXISTS incidents (
    id INT AUTO_INCREMENT PRIMARY KEY,
    monitor_id INT NOT NULL,
    started_at DATETIME NOT NULL,
    resolved_at DATETIME NULL,
    status ENUM('open', 'resolved') DEFAULT 'open',
    cause TEXT,
    fail_count INT DEFAULT 1,
    duration_seconds INT DEFAULT 0,
    FOREIGN KEY (monitor_id) REFERENCES monitors(id) ON DELETE CASCADE
);

```

#### B. MongoDB Initialization

Ensure your MongoDB instance is running locally or accessible via your `MONGO_URI`. The `checkresults` collection will automatically be generated by Mongoose when the service executes its first check run.

---

### 5. Configure Google App Password for Email Alerts

To enable the application to send automated alert emails to arbitrary recipient addresses:

1. Log into your [Google Account](https://myaccount.google.com/).
2. Navigate to **Security** and ensure **2-Step Verification** is turned ON.
3. Open the direct App Passwords page: [https://myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords).
4. Create a new App Password named `Service Consistency Checker`.
5. Copy the generated 16-character code and paste it as the `GMAIL_APP_PASS` value in your `.env` file (spaces do not matter).
6. Set `GMAIL_USER` to your Gmail address and `ALERT_EMAIL_TO` to the recipient address(es).

---

### 6. Reset Test Data (Optional)

If you need to wipe existing test metrics, logs, or check runs across both MySQL and MongoDB, run the utility script:

```bash
node reset-db.js

```

---

### 7. Run the Web Application

#### Development Mode (with hot reloading)

```bash
npm run dev

```

#### Production Mode

```bash
npm start

```

Once the server has started successfully, open your web browser and navigate to:

```
http://localhost:3000

```
